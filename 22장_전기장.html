22장 전기장

쿨롱 법칙에서 시작해 전기장을 정의하고, 균일한 전기장 안에서 전하가 어떻게 움직이는지까지 다룬다. 교수님이 이 장에서 짚은 건 연습 10번과 예제 22.5의 풀이법 3가지다.

용어 정의 공식 전기력선 연습 10 예제 22.5 다른 예제 점검
§1

용어 정의

시험은 "정의를 쓰고 → 계산"하는 순서로 나온다. 정의를 빼먹으면 답이 맞아도 감점이다. 가리고 외우기를 켜면 정의가 흐려지고, 카드를 누르면 하나씩 보인다.

쿨롱 법칙★
두 점전하 사이에 작용하는 정전기력의 크기는 \(F_e = k_e \dfrac{|q_1||q_2|}{r^2}\)이다. 힘은 두 전하를 잇는 방향의 벡터(\(\vec F_{12} = k_e\frac{q_1q_2}{r^2}\hat r_{12}\))이고, \(\vec F_{12} = -\vec F_{21}\)이다.
\(k_e = 1/4\pi\varepsilon_0\). 셋 이상이면 벡터 합: \(\vec F_1 = \vec F_{21} + \vec F_{31} + \cdots\) 슬라이드 22.3 · 수식 그대로
전하의 특성★
양전하와 음전하 두 종류가 있다. 같은 종류끼리는 밀어내고 다른 종류끼리는 당긴다. 고립계에서 전하량은 보존되고, 기본 전하 \(e\)의 정수배로만 존재한다(양자화).
\(e = 1.60\times10^{-19}\ \mathrm{C}\), \(Q = ne\) 슬라이드 22.1 · 그대로
전기장★
원천 전하가 주변 공간에 만드는 영역. 그 점에 놓인 시험 전하가 받는 단위 전하당 전기력으로 정의한다.
\(\vec E \equiv \vec F_e / q_0\), 단위 N/C (= V/m) 슬라이드 22.4 + 녹취 9/8·9/17
원천 전하와 시험 전하
전기장은 원천 전하가 만든다. 시험 전하는 전기장이 있는지 알아내는 검출기 역할만 하고, 전기장을 만들지 않는다.
아무 말이 없으면 그 점에 +1 C가 있다고 생각한다. 슬라이드 22.4 + 녹취 9/8
전기력선
전기장을 눈으로 보이게 그린 선. 각 점의 접선이 전기장 방향이고, 선의 밀도가 전기장의 세기를 나타낸다.
+에서 나와 −로 들어간다. 나오는 선 수 ∝ 전하량. 서로 교차하지 않는다(꼬인 위치는 가능). 슬라이드 22.5 · 그대로
전기적 차폐
같은 부호(+, +) 전하의 전기력선이 서로 튕겨 나가 전기장이 존재하지 않는 빈 공간이 생기는 것. 전기장이 없으므로 전기적인 역할이 전혀 없다(수학적으로 \(E = 0\)).
전자레인지 전자기파 차폐 같은 응용 녹취 9/8·9/10 · 교수님 표현
일 (에너지 쪽 도구)
한 에너지가 다른 형태로 전환될 때, 전환되는 에너지의 양을 정량화한 것.
\(W = F\Delta x\). 운동 에너지로 바뀌면 \(W = \Delta K\) 녹취 9/10 · 교수님 정의
고립계와 비고립계
고립계는 에너지가 계 밖으로 드나들지 않아 역학적 에너지가 보존되는 계(\(\Delta K + \Delta U = 0\)). 비고립계는 외부가 일을 해 주는 계로, 일-에너지 정리(\(W = \Delta K\))를 쓴다.
22.5 풀이법 ②와 ③을 가르는 기준 녹취 9/10·9/22 · 문장은 정리본
§2

핵심 공식

힘은 벡터다. 크기를 먼저 구하고, 방향(척력·인력)을 따로 정한 다음 성분별로 더한다.

쿨롱 상수\(k_e = \dfrac{1}{4\pi\varepsilon_0} = 8.99\times10^{9}\ \mathrm{N\,m^2/C^2},\quad \varepsilon_0 = 8.85\times10^{-12}\ \mathrm{C^2/N\,m^2}\)
두 전하 사이의 힘 (벡터)\(\vec F_{12} = k_e\dfrac{q_1q_2}{r^2}\,\hat r_{12},\qquad \vec F_{12} = -\vec F_{21}\)
여러 전하 (중첩)\(\vec F_1 = \vec F_{21} + \vec F_{31} + \vec F_{41} + \cdots\)
점전하의 전기장\(\vec E = \dfrac{\vec F_e}{q_0} = k_e\dfrac{q}{r^2}\,\hat r\)
전기장 안의 전하\(\vec F_e = q\vec E = m\vec a \;\Rightarrow\; \vec a = \dfrac{q\vec E}{m}\) (균일하면 등가속도)
등가속도 운동\(v_f^2 = v_i^2 + 2a(x_f - x_i),\quad x_f = x_i + v_i t + \tfrac12 a t^2\)
평형\(\sum \vec F = 0\) — "힘이 없다"보다 "평형이다"로 쓴다
쌍극자 (멀리, \(y \gg a\))\(E \approx k_e\dfrac{2aq}{y^3}\)
§3

전기력선 그려보기

배치를 바꿔 보면서 세 가지를 확인하자. 선은 +에서 나와 −로 들어가고, 서로 교차하지 않으며, 같은 부호 사이에는 전기장이 0인 빈 공간(차폐)이 생긴다. 그림을 누르면 그 점에 +1 C 시험 전하를 놓았을 때 받는 힘의 방향이 화살표로 나온다.

양전하음전하

그림을 누르면 시험 전하(+1 C)에 작용하는 힘의 방향이 표시됩니다.

§4

연습 10(10) · 일직선 위의 세 점전하

교재 필기에 찍어준 문제. 대상 전하 하나를 정하고, 나머지 두 전하가 주는 힘을 각각 구한 뒤 방향을 따져서 더한다.

시험 후보

세 전하 각각에 작용하는 전기력의 크기와 방향

\(q_1 = 6.00\ \mu\mathrm C,\ q_2 = 1.50\ \mu\mathrm C,\ q_3 = -2.00\ \mu\mathrm C\), \(d_1 = 3.00\ \mathrm{cm}\) (\(q_1\)–\(q_2\)), \(d_2 = 2.00\ \mathrm{cm}\) (\(q_2\)–\(q_3\)). (a) \(q_1\), (b) \(q_2\), (c) \(q_3\)에 작용하는 힘.
화살표 길이는 힘의 크기에 비례 (같은 축척)

풀이
  1. 쌍마다 힘의 크기를 먼저 구한다 (부호는 빼고 크기만).
    \[F_{12} = k_e\frac{|q_1||q_2|}{d_1^2} = (8.99\times10^9)\frac{(6.00\times10^{-6})(1.50\times10^{-6})}{(0.0300)^2} = 89.9\ \mathrm N \ \ (\text{척력})\]
    \[F_{13} = k_e\frac{|q_1||q_3|}{(d_1+d_2)^2} = (8.99\times10^9)\frac{(6.00\times10^{-6})(2.00\times10^{-6})}{(0.0500)^2} = 43.2\ \mathrm N \ \ (\text{인력})\]
    \[F_{23} = k_e\frac{|q_2||q_3|}{d_2^2} = (8.99\times10^9)\frac{(1.50\times10^{-6})(2.00\times10^{-6})}{(0.0200)^2} = 67.4\ \mathrm N \ \ (\text{인력})\]
  2. 오른쪽을 \(+\hat i\)로 잡고 대상마다 방향을 붙여 더한다.
    \[\vec F_1 = \underbrace{-89.9\,\hat i}_{q_2\text{가 밀어냄}} + \underbrace{43.2\,\hat i}_{q_3\text{가 당김}} = -46.7\,\hat i\ \mathrm N\]
    \[\vec F_2 = \underbrace{+89.9\,\hat i}_{q_1\text{가 밀어냄}} + \underbrace{67.4\,\hat i}_{q_3\text{가 당김}} = +157\,\hat i\ \mathrm N\]
    \[\vec F_3 = \underbrace{-43.2\,\hat i}_{q_1\text{이 당김}} + \underbrace{(-67.4\,\hat i)}_{q_2\text{가 당김}} = -111\,\hat i\ \mathrm N\]
  3. 검산: 내력만 있으므로 세 힘의 합은 0이어야 한다. \(-46.7 + 157.3 - 110.6 \approx 0\) ✓

(a) 46.7 N, 왼쪽  ·  (b) 157 N, 오른쪽  ·  (c) 111 N, 왼쪽

함정: 크기 계산에는 전하의 부호를 넣지 말고, 방향은 척력·인력으로 따로 정한다. 거리 \(r_{13} = d_1 + d_2 = 5.00\ \mathrm{cm}\)이고, cm는 m로 바꾼다.

§5

예제 22.5 · 속도를 구하는 세 가지 방법

교수님이 "다시 테스트할 확률이 80%"라고 한 문제. 24장 예제 24.2와 묶어서 비교 문제로 나올 수 있다. 같은 답을 세 가지 도구로 끌어내는 게 핵심이다.

시험 후보 ★★

평행판 사이에서 가속되는 양전하

간격 \(d\)인 평행판 사이에 균일한 전기장 \(E\)(+x 방향). 양전하 판 근처 A점에 질량 \(m\), 전하 \(q\)인 양전하를 정지 상태에서 놓으면 음전하 판 근처 B점으로 가속된다. B점에서의 속력은?
t = 0 · x = 0 · v = 0

점 사이 간격이 갈수록 넓어진다: 같은 시간 간격 동안 더 멀리 간다는 뜻이다(등가속도). 전기장이 균일하면 어디서나 힘 \(qE\)가 같다.

방법언제 쓰나출발식 → 결과
① 힘
등가속도 모형		가속도·시간을 물을 때\(a = \dfrac{qE}{m}\), \(\ v_f^2 = 0 + 2a(d - 0)\) \(\Rightarrow v_f = \sqrt{2ad}\)
② 비고립계
일-에너지 정리		"계"에 대한 말이 없을 때\(W = \Delta K\): \(\ qEd = \tfrac12 mv_f^2 - 0\)
③ 고립계
역학적 에너지 보존		"전하와 전기장이 한 계" (24장)\(\Delta K + \Delta U = 0\): \(\ \tfrac12mv^2 + q\Delta V = 0,\ \Delta V = -Ed\)

세 방법 모두 \(\displaystyle v_B = \sqrt{\frac{2qEd}{m}}\)

풀이 ①, ②를 답안처럼 써 보기
  1. (A) 등가속도 모형. 균일한 전기장이므로 힘이 일정하다.
    \[F = qE = ma \;\Rightarrow\; a = \frac{qE}{m}\]
    \[v_f^2 = v_i^2 + 2a(x_f - x_i) = 0 + 2a(d - 0) = 2ad \;\Rightarrow\; v_f = \sqrt{2\left(\frac{qE}{m}\right)d} = \sqrt{\frac{2qEd}{m}}\]
  2. (B) 비고립계 모형. 전기장이 입자에 일을 해 준다. 위치 에너지는 쓰지 않는다.
    \[W = \Delta K:\quad F_e\Delta x = K_B - K_A = \tfrac12 mv_f^2 - 0\]
    \[v_f = \sqrt{\frac{2F_e\Delta x}{m}} = \sqrt{\frac{2(qE)(d)}{m}} = \sqrt{\frac{2qEd}{m}}\]

속도를 물으면 에너지로 바로 가는 게 좋다. ①은 가속도를 거쳐 한 단계를 더 건너간다. 숫자 없이 문자식으로 끝나도 되는 문제다.

함께 볼 예제와 과제

예제 22.2

직각삼각형 꼭짓점의 세 전하

\(q_1 = q_3 = 5.00\ \mu\mathrm C\), \(q_2 = -2.00\ \mu\mathrm C\), \(a = 0.100\ \mathrm m\). \(q_3\)에 작용하는 알짜힘.
풀이
  1. \(F_{23} = k_e\dfrac{(2.00)(5.00)\times10^{-12}}{(0.100)^2} = 9.0\ \mathrm N\) (인력, \(-x\))
  2. \(F_{13} = k_e\dfrac{(5.00)(5.00)\times10^{-12}}{2(0.100)^2} = 11\ \mathrm N\) (척력, 45° 방향)
  3. \(F_{13x} = F_{13y} = 11\cos45^\circ = 7.9\ \mathrm N\)
  4. \(F_{3x} = 7.9 - 9.0 = -1.1\ \mathrm N,\ F_{3y} = 7.9\ \mathrm N\)

\(\vec F_3 = (-1.1\,\hat i + 7.9\,\hat j)\ \mathrm N\) — 최종 답은 이 벡터 형식으로

예제 22.3

알짜힘이 0인 위치

\(q_2 = 6.00\ \mu\mathrm C\)가 원점, \(q_1 = 15.0\ \mu\mathrm C\)가 \(x = 2.00\ \mathrm m\). \(q_3\)가 평형인 위치는?
풀이
  1. 두 전하 사이에서 크기가 같고 방향이 반대인 점을 찾는다. \(\sum F = 0\):
    \[k_e\frac{q_2q_3}{x^2} = k_e\frac{q_1q_3}{(2.00 - x)^2}\]
  2. \(q_3\)는 지워진다. \((2.00 - x)\sqrt{q_2} = x\sqrt{q_1}\)
    \[x = \frac{2.00\sqrt{q_2}}{\sqrt{q_2} + \sqrt{q_1}} = \frac{2.00\sqrt{6.00}}{\sqrt{6.00} + \sqrt{15.0}} = 0.775\ \mathrm m\]

\(x = 0.775\ \mathrm m\) (원점 기준). 이차방정식의 다른 근은 두 전하 바깥이라 힘이 같은 방향이므로 버린다.

예제 22.4

두 전하에 의한 전기장, 쌍극자

\(q_1\)이 \((-a,0)\), \(q_2\)가 \((b,0)\)에 있다. 점 \(P(0,y)\)에서의 전기장. (B) \(|q_1| = |q_2|,\ a = b\), (C) \(y \gg a\)
풀이
  1. 순서대로: 거리 \(r_1, r_2\) → 각 전기장의 크기 → 성분 분해 → 같은 성분끼리 더하기.
    \[E_1 = k_e\frac{|q_1|}{a^2 + y^2},\quad E_2 = k_e\frac{|q_2|}{b^2 + y^2}\]
  2. (B) +q, −q 쌍극자면 y성분은 상쇄되고 x성분만 남는다.
    \[E_x = 2k_e\frac{q}{a^2 + y^2}\cos\theta,\quad \cos\theta = \frac{a}{\sqrt{a^2 + y^2}} \;\Rightarrow\; E = k_e\frac{2qa}{(a^2 + y^2)^{3/2}}\]
  3. (C) 멀리서 보면 \(a^2\)을 무시: \(E \approx k_e\dfrac{2qa}{y^3}\). 거리의 3제곱에 반비례한다.

교수님 요령: 크기 → 벡터 성분 → 합의 순서를 지킨다. 교재 풀이 순서를 그대로 믿지 말고 자기 순서로 정리할 것.

예제 22.6

전기장에 수평으로 들어온 전자

\(E = 200\ \mathrm{N/C}\), \(v_i = 3.00\times10^6\ \mathrm{m/s}\), 판 길이 \(\ell = 0.100\ \mathrm m\). 옥상에서 수평으로 던진 공과 같은 포물선 운동이다.
풀이
  1. (A) \(a_y = -\dfrac{eE}{m_e} = -\dfrac{(1.60\times10^{-19})(200)}{9.11\times10^{-31}} = -3.51\times10^{13}\ \mathrm{m/s^2}\)
  2. (B) x방향은 등속: \(t = \dfrac{\ell}{v_x} = \dfrac{0.100}{3.00\times10^6} = 3.33\times10^{-8}\ \mathrm s\)
  3. (C) \(y_f = \tfrac12 a_y t^2 = \tfrac12(-3.51\times10^{13})(3.33\times10^{-8})^2 = -1.95\ \mathrm{cm}\)

좌표 원점을 들어오는 점에 잡았으므로 아래쪽이 음수다. 계산에서 마이너스가 나와도 당황하지 말 것.

과제 11(11)

세 전하 중 +Q가 받는 알짜힘

\(+2Q\)가 원점, \(-Q\)가 \((d, 0)\), \(+Q\)가 \((0, d)\). \(+Q\)가 받는 알짜힘의 식.
풀이
  1. \(+2Q\)의 척력: 거리 \(d\), 방향 \(+\hat j\). \(\ \vec F_a = k_e\dfrac{2Q^2}{d^2}\,\hat j\)
  2. \(-Q\)의 인력: 거리 \(\sqrt2 d\), \((0,d)\)에서 \((d,0)\)을 향함, 방향 \(\dfrac{\hat i - \hat j}{\sqrt2}\).
    \[\vec F_b = k_e\frac{Q^2}{2d^2}\cdot\frac{\hat i - \hat j}{\sqrt2} = k_e\frac{Q^2}{2\sqrt2\,d^2}(\hat i - \hat j)\]
  3. 더하기:
    \[\vec F = k_e\frac{Q^2}{d^2}\left[\frac{1}{2\sqrt2}\,\hat i + \left(2 - \frac{1}{2\sqrt2}\right)\hat j\right] \approx k_e\frac{Q^2}{d^2}\left(0.354\,\hat i + 1.65\,\hat j\right)\]
